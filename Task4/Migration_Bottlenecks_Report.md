Дорожная карта приоритетов:
Недели 1-2:
   • Выбор стратегии (strangler fig)                                  
   • Развёртывание CI/CD (GitLab CI)                                  
   • План отката (blue-green) 
Недели 3-6:
   • ETL для миграции Excel → PostgreSQL                             
   • Staging-слой + валидация данных                                  
   • Развёртывание k8s кластера                                       
   • Prometheus + Grafana мониторинг 
Недели 7-10:
  • Адаптер для лаборатории (SFTP → API)                             
  • Миграция SMB → MinIO S3                                          
  • Найм senior DevOps + обучение 
Недели 11-14:
  • Постепенная миграция по частям (strangler)                       
  • Dual-write на время миграции                                     
  • Нагрузочное тестирование
Недели 15-16:
  • Переезд на финальные сервисы
  • Ликвидация старой системы


Отчет по результатам:
|Вывод      |Обоснование                |
|------------|------------------------|
|Самое узкое место — данные|Excel без ключей, дубликаты, неструктурированность. ETL будет самым сложным этапом|
|Инфраструктура требует полной замены|Один сервер, отсутствие мониторинга. Без этого новая архитектура не взлетит|
|Необходима стратегия постепенной миграции|Big Bang невозможен из-за риска даунтайма, бизнес не готов|
|Ключевой риск — персонал|Нет опыта в микросервисах, DevOps, DBA — нужен найм или обучение. Приоритет отдать найму сеньров|
