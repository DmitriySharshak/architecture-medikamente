|------------|------------------------|----------|--|--|--| 
|Медицинская тайна|Диагнозы, история болезни, анализы|At Rest / In Transit|Критичный|Штрафы, уголовная ответственность|1 (высший)|

|Финансовые данные|Суммы платежей, зарплаты|At Rest / In Transit|Средний|Коммерческая тайна|2 (средний)|
|Учётные данные|Логин, JWT токены|At Rest / In Transit|Критичный|Компрометация|1 (высший)|

|Складские данные|Остатки, поставщики|At Rest / In Transit|Низкий|Операционные риски|3 (низкий)|

Инструменты защиты данных:
1. Шифрование при хранении

|Место хранения      |Инструмент                |Метод|Обоснование|
|------------|------------------------|----------|--|
|PostgreSQL (PII/Medical)|pgcrypto|AES-256, column-level encryption|Колоночное шифрование позволяет RLS + гибкость|
|Файлы (S3-совместимое)|MinIO|AES-256|Прозрачное шифрование без изменения приложений|
|Диски серверов|BitLocker|AES-256|Защита от физической кражи|
|Логи|ELK с шифрованием на диске|AES-256|Логи содержат обфусцированные PII|

2. Шифрование при передаче

|Канал передачи      |Инструмент                |Метод|Обоснование|
|------------|------------------------|----------|--|
|Web/API|HTTPS|TLS 1.3 (только последний) |Запрет устаревших протоколов|
|Сервис - Сервис|mTLS |TLS 1.3 + взаимная аутентификация|принцип нулевого доверия|
|БД - Приложение|PostgreSQL TLS|TLS 1.3|Шифрование соединения с БД|
|Внешние интеграции |API Gateway + mTLS|TLS 1.3 + client cert|Двусторонняя аутентификация|
