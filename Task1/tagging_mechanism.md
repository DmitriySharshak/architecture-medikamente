Механизм тегирования данных:
1. Список тегов

|Тэг         |Значения                |Примечание|
|------------|------------------------|----------| 
|confidential|Медицинская тайна, PII  |Обязательное шифрование, аудит доступа|
|public      |Прейскуранты, расписание|Без ограничений|
|pii-direct  |ФИО, телефон, email     |Маскировать в логах, шифровать|
|pii-indirect|Пол, возраст, город     |Для проведения аналитики|
|laboratory  |От лаборатории          |Проверять целостность подписью|
|reception   |От ресепшена            |Минимальные привилегии|

2. Инструменты для тегирования
Apache Atlas / Amundsen    — для Data Catalog + тегирования в озере данных.
AWS Macie / Google DLP API — автоматическое обнаружение PII и навешивание тегов.
Varonis / Netwrix          — для файловых шаров (тегирование через Extended Attributes).
Open Policy Agent (OPA)    — для ABAC на основе тегов.

3. Меры по обеспечению конфиденциальности

|Поток|Мера|
|-----|----|
|Сбор данных|Формы с маскированием, согласие на обработку ПДн|
|Передача|TLS 1.3 везде (API, веб)|
|Хранение|Шифрование at-rest (AES-256)|
|Доступ|RBAC (роли) + ABAC (атрибуты: отдел, цель доступа, согласие пациента)|
|Удаление|Скрипты по расписанию|
|Мониторинг|Алерты на аномалии работы с данными, например интенсивное скачивание данных|
|Аудит|Логирование всех операций с данными: read, write, delete, export|
